# עבודות לאתר

כל תמונה או סרטון שמעלים לתיקייה הזו מופיעים לבד בגלריית העבודות באתר.

**איך מעלים (גם מהטלפון):** נכנסים לתיקייה הזו ב-GitHub ← Add file ← Upload files ← בוחרים קבצים ← Commit changes.

- **סוגי קבצים:** תמונות JPG, PNG או WebP. סרטונים MP4 (מומלץ). קבצי MOV מאייפון לא תמיד מתנגנים בדפדפנים, לכן עדיף לייצא ל-MP4.
- **גודל:** עד 25MB לקובץ בהעלאה דרך האתר של GitHub. לסרטון אתר מספיק 1080p קצר.
- **סדר:** לפי שם הקובץ. אפשר להוסיף מספר בהתחלה: `01 ...`, `02 ...`.
- **כיתוב:** שם הקובץ הופך לכותרת. מקף עם רווחים מפריד בין כותרת לתיאור: `01 מגדל בתל אביב - הדמיית חוץ.jpg`. שמות כמו `IMG_1234` מוצגים בלי כיתוב.
- **סרטונים** מתנגנים לבד, בלי קול ובלולאה, כשהם על המסך. לחיצה פותחת אותם בגדול עם קול.
- **הסרה:** מוחקים את הקובץ מהתיקייה.
